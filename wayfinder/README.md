# Project map and decisions

The project's decisions, tickets and build plan live in **GitHub issues**, not in this folder:

- Start at the map issue, "Map: flight tracker on a 64x32 HUB75 panel" (issue 35). It lists every decision with a one-line gist and links to the ticket that holds the detail, and lists the open build slices.
- Tickets are issues with the labels `wayfinder:grilling`, `wayfinder:research` or `wayfinder:task`; build slices carry the label `build`.
- Ticket numbers carried over from the earlier local files (ticket 015 is issue 15). Those files were removed in the migration and remain in this repository's git history under `wayfinder/tickets/` and `wayfinder/map.md`.

`research/` keeps the longer research notes that tickets refer to.
