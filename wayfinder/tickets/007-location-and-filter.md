## Question

Where is the panel (lat/lon), what search radius, and which flights count (all, descending/landing, below N feet, hide ground traffic)? Where do those settings live?

**Answered so far (owner, 21 Nov 2026):** all settings are changed in a web portal that the S3 itself serves, LAN only, reachable by an mDNS name. The portal sets the location on a map, the radius and the altitude, and the Wi-Fi network. After a reset the S3 starts its own access point so the Wi-Fi can be configured the first time. Still open: which flights count beyond altitude, exact filter semantics, defaults.
