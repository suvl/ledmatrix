LedMatrix screen previews

Every screen the device will show, drawn at the real 64×32 resolution with the same pixel fonts the firmware will use. Layouts are candidates to react to. All flight, weather and headline text is example data, and the airline logos are placeholder drawings.

64×32 pixels 6×8 font: 10 characters per line 4×6 font: 16 characters per line 16×16 logo block

Flight card

Shown once when a plane enters the radar, for the time set on the portal (default 10 s).

Weather

Shown when no plane is on screen.

Headlines

Cycled when there is a new headline and no plane is on screen.

Idle

Nothing to show: no plane, weather or headline.

Setup mode

After a long press on UP. The password is generated each time and shown here. The network name is the display name (“ledmatrix” until you choose another): up to 10 characters it is drawn big, a longer one in small letters on up to two lines.

Status screens

Boot, connected, stale data, no Wi-Fi, and the problem message (5 seconds once a minute after something has failed for an hour; never over a plane or a headline, dark at night). Connected and the problem message show the display name as <name>.local; a long name is cut to the width.

Firmware update

Two screens shown instead of the normal ones while an update is under way (never dimmed, never drifting). First the code the owner types into the portal to allow it: six digits, valid for 3 minutes (the bar on the last row counts them down and turns red for the last 30 seconds). Then the progress of the download, or of an uploaded file, whose version is not known.

Fonts are the Adafruit GFX default 5×7 (6×8 cell) and Tom Thumb 3×5 (4×6 cell), read from the library installed for the firmware. A red badge means a line is wider than the space it is given, and the preview cuts it where the panel would. Real logos would be 16×16 bitmaps sent by the cloud service and stored on the device.
